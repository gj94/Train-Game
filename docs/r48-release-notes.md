# R48: Optional Coastal Network timetable

Choose **Predictive V2 · Coastal Network 179 (long waits)** on Home. The existing Classic and Predictive V2 Standard 100 and Intensive 140 timetables remain available.

The new day includes 40 local, 80 mail/express, 51 superfast and 8 Vande Bharat services, with overnight departures and through trains entering or leaving beyond Ernakulam and Nagercoil. These are representative game services, not an official railway timetable.

Long waits are expected. This release explicitly accepts missed cumulative wait targets for this optional day. The normal test completed all 179 services, all 2,443 arrivals and departures, 84 full-tail boundary exits and 95 depot workings with zero safety events. The separate test with a ten-minute K1 delay also completed all services with zero safety events. Actual full-formation overtakes occurred at 24 locations in the normal run and 26 in the delayed run.

The longest recorded continuous wait was 44m04s in the normal test and 40m56s in the delayed test. Endpoint delays can be longer than a single wait. These are measured AI outcomes, not guarantees for manual driving. The original failed wait-quality audit remains recorded; safety and completion requirements were retained.

## Try the new timetable

1. Start R48 and select Coastal Network 179 on Home.
2. Browse a local or through service, inspect its calls and measured traffic, then drive or ride it.
3. Open the time browser at noon or day-two midnight; choose an active service.
4. Save, return to Home, and load that journey. Its selected timetable and complete railway state should return paused.
5. Select Standard or Intensive whenever you prefer the existing timetables.

Start a new journey to use this timetable. Existing saves retain their own railway and timetable; this release does not replace them. Full ZIP downloads and incremental Update & Play v4 are supported. No new universal frame-rate or wait-performance claim is made.
